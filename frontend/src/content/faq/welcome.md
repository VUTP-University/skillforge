# Welcome to SkillForge

*A place to prove your code works — not just that you think it does.*

SkillForge is a platform for leveling up as a programmer, one solved problem at a time. Write code, run it against real checks, and watch your XP climb as you go.

---

## What's Here

- **The Job Board** — Programming problems across four languages, each one a self-contained challenge with its own checks to pass
- **The Stack Trace** — A harder arena of hostile processes, reserved for coders who've already proven the basics
- **The Test Suite** — A weekly timed run across all four languages, testing breadth instead of depth
- **The Leaderboard** — Every user on SkillForge, ranked by total XP

## How to Begin

Register an account and you're in — no waiting, no approval process.

From the **Dashboard**, pick a language and start your first job. Each one you clear — cleanly, on the first try — earns XP. XP raises your level, and your level determines your rank.
